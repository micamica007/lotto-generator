# 🎲 동행복권 6/45 통계 기반 가중치 5게임 번호 생성기

동행복권 최신 당첨 데이터(API)를 실시간으로 연동하여 최근 출현 빈도를 분석하고, 많이 나온 번호에 가중치를 부여하는 **가중치 랜덤 추첨(Weighted Random Sampling)** 알고리즘 기반 5게임(A~E) 번호 생성기입니다.

---

## ✨ 주요 기능

1. **가중치 5게임 자동 추출 (A, B, C, D, E)**
   - 가중치 공식: $\text{Weight}(n) = \text{Count}(n) + \text{Base Weight} \quad (\text{Base Weight} = 1)$
   - 출현 빈도가 높은 번호일수록 나올 확률 상승, 미출현 번호도 최소 확률 보장.
   - 각 게임 내 6개 숫자는 중복 없이 **오름차순 정렬**.
   - 원클릭 **5게임 전체 복사** 지원.

2. **고정 번호 및 제외 번호 맞춤 설정**
   - **고정 번호**: 최대 5개까지 지정 가능 (모든 게임에 필수 포함 후 나머지 자동 추첨).
   - **제외 번호**: 최대 10개까지 지정 가능 (1~45 추첨 리스트에서 완전히 제거).

3. **실시간 동행복권 데이터 연동 & 통계 대시보드**
   - 최신 회차 당첨 번호, 보너스 번호, 1등 당첨금액 및 인원수 자동 조회.
   - 최근 20회, 30회, 50회차 당첨 데이터 병렬 집계.
   - HOT 번호 TOP 5(다출수) & COLD 번호 TOP 5(과소출수) 요약.
   - 1~45 번호별 출현 빈도 막대 그래프 및 히트맵 뷰.

4. **공식 로또 공 색상 시스템**
   - 1~10: 노란색 (`#FBC400`)
   - 11~20: 파란색 (`#69C8F2`)
   - 21~30: 빨간색 (`#FF7272`)
   - 31~40: 회색 (`#AAAAAA`)
   - 41~45: 초록색 (`#B0D840`)

## 🛠️ 기술 스택

- **Frontend**: React 18, Vite, Tailwind CSS, Lucide React
- **Backend**: Node.js, Express (CORS 프록시 및 최근 통계 캐싱)
- **Testing**: Node.js Assert (단위 테스트), CDP Chrome Headless (E2E 테스트)
